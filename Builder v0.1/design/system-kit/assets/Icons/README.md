# Icons

The app's line icons as standalone SVGs: 24-unit grid, 1.6 stroke, round caps and joins. These files are drawn in `bc-ink` (#ececed) because `<img>` cannot inherit colour — use them where an image is needed (docs, exports). In the UI use the `Icon` component, which draws the same paths in `currentColor`.

`home`, `clock` (Recents), `folder` (Projects), `project` (composer picker), `cube` (Mechanical), `bolt` (Electrical), `chip` (Controls), `wave` (Simulation), `clipboard` (Assessments), `tag` (Quotes), `doc` (Documentation), `check` (Testing), `book` (Standards library), `sparkle` (Ask AI), `help` (Support), `search`, `plus`, `send`, `arrow-up-right`, `chevron-right`, `chevron-down`, `chevron-updown` (workspace switcher), `account` (Manage account), `star` (Favorites), `more`.
