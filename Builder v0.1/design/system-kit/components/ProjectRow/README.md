# ProjectRow

A project in a list: mono BC-Q number and stage, the project name, and StageProgress.

- Props: `number` (BC-Q-YYNNN), `name`, `step`, `stage` (Assessment, Design, Build, FAT, SAT), `onClick`.
- Rows are separated by `bc-hairline` rules, not cards. Use under a mobile SectionHeader ("Active projects", "See all").
