# MobileComposer

The mobile input: a 64px light pill with an 18px input and a 48px send button, docked above the TabBar.

- Props: `placeholder` (default "Describe the problem"), `value`/`defaultValue`, `onChange`, `onSend`.
- Disarmed send is `bc-field-send-off` with a `bc-field-muted` arrow (same on desktop); armed is `bc-steel-blue`.
