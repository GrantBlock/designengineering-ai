# Tag

A one-word mono label: `New` on a nav item or chip, a count beside a section header.

- Props: `plain` (no tint — muted count text), `children` (one or two words).
- Overpass Mono 10px, 0.1em, uppercase; `bc-steel-blue-text` on `bc-steel-blue-tint`, `bc-radius-control` corners.
- Not a status system: there are no success/warning/error tags in the app yet.
