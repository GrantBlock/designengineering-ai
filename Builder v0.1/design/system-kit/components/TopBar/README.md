- Props: `crumb` (e.g. "Mechanical  /  Parts" — two spaces either side of the slash), `actions` (Buttons; defaults to New session, Ask AI, Support), `initial`, `onNew`.
- 56px tall, `bc-hairline` underline, `bc-space-6` side padding.
