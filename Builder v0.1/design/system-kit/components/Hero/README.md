# Hero

The opening of an empty page: optional chips, a steel-blue mono eyebrow, and an uppercase Overpass ExtraBold question.

- Props: `eyebrow`, `title`, `actions` (chip Buttons above), `mobile` (left-aligned, 42px title).
- The title is a question or a plain statement in the second person, uppercase, ≤ 6 words: "What are we building today?". The eyebrow names the workspace.
- One hero per page, only while the page is empty. Once a conversation starts, it goes.
